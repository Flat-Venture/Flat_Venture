# 플랫 벤처 게임 기획서

> 문서 상태: 초안 1.0  
> 개발 환경: Unity 6.3 LTS, Visual Studio  
> 장르: 3D 로그라이크 액션 RPG  
> 목표 범위: 3개 스테이지와 3개 직업으로 한 사이클 완성

## 1. 게임 개요

플랫 벤처는 마을에서 영구 성장과 직업을 정비한 뒤, 시드 기반 던전에 진입하여 노드를 선택하고 전투·보상·정비를 반복하는 3D 로그라이크 게임이다. 아이템을 5×5 인벤토리에 배치해 속성 빙고와 시너지를 만들고, 아이템에 부여된 액티브·패시브 스킬을 조합하는 것이 핵심이다.

### 핵심 재미

- 노드와 방을 선택하며 매번 달라지는 던전 공략
- 5×5 인벤토리 배치와 속성 빙고를 통한 빌드 구성
- 아이템 및 동일 스킬 중첩을 통한 스킬 성장
- 계정·직업·런 단위로 나뉜 단계적 성장
- 엘리트 특성과 보스 패턴에 맞춘 전투 대응

## 2. 목표와 현재 상태

### 현재 구현

- 플레이어블 직업 1종: 전사
- 인벤토리
- 아이템 및 아이템 속성
- 모든 직업이 공유하는 계정 특성
- 설정 및 특성 세이브/로드

계정 특성은 직업이 하나뿐인 현재 구조를 기준으로 만들어졌으므로, 추가 직업 제작 과정에서 범용성을 다시 검증한다.

### 1차 개발 목표

- 3개 스테이지를 잇는 전체 플레이 사이클 완성
- 전사, 궁수, 마법사 총 3개 직업 완성
- 업적 시스템 구현
- 층 또는 관문 단위 진행 저장
- 시드 기반 랜덤 시스템 통합

### 우선 재작업 대상

- 몬스터 전반
- 맵과 지도 전반
- 던전 및 보상 생성
- 몬스터 풀
- 상점 판매 목록
- 미지 노드
- 제련, 강화, 승급
- 레벨업 보상
- 리롤을 포함한 모든 랜덤 요소

## 3. 전체 게임 흐름

```text
게임 시작
  → 마을에서 계정/직업 성장 및 정비
  → 던전 입장
  → 시드 생성 및 노드 지도 구성
  → 이동과 전투
  → 아이템 보상 및 인벤토리 빌드 구성
  → 상점/제련소/이벤트/휴식
  → 보스
  → 다음 막 또는 마을 귀환
  → 진행 저장 후 다음 플레이
```

중도 종료 시 런 진행을 저장하고, 재실행 시 로드할 수 있도록 한다.

## 4. 조작과 카메라

| 동작 | 입력 |
|---|---|
| 이동 | WASD |
| 기본 공격 | 자동 조준, 좌클릭 시 수동 조준 |
| 대시 | Space Bar |
| 상호작용 | F |
| 포션 | 숫자 1~0 후보 |
| 기타 스킬 | Q, E, R, T, G, X, C, V, B, Shift, Ctrl 후보 |

- 초기 카메라는 고정 방식으로 구현한다.
- 카메라 회전이 실제 전투에 필요한지는 프로토타입으로 검증한다.
- 플레이어는 임시 Sprite, 맵과 구조물은 기본 3D 에셋으로 제작한다.

## 5. 성장 구조

성장은 계정 성장, 직업 성장, 런 성장의 세 층으로 구분한다.

### 5.1 계정 성장

모든 직업이 공유하는 영구 성장이다. 계정 레벨 상한은 약 50을 후보로 두며, 성장 속도는 느리게 설계한다. 최종적으로 모든 특성을 획득할 수 있더라도 플레이 중에는 코스트 때문에 선택과 집중이 발생하도록 한다.

계정 특성 후보:

- 공격력, 주문력, HP
- 받는 피해 감소, 회피율, 보호막
- 기본 공격 속도, 이동 속도, 시전 속도
- 액티브 스킬 및 대시 쿨타임, 대시 횟수
- 치명타 확률 및 치명타 피해
- 경험치 및 골드 획득량
- 투사체 개수, 속도, 크기
- 기본 공격 및 스킬 범위
- 생명력 흡수, 회복, 정화, 강인함
- 주는 피해 증가
- 행운 기반 변동 효과

특성 코스트 예시:

- 부활: 5
- 경험치 획득량 증가: 3
- 공격력 증가: 단계당 1, 최대 5단계

### 5.2 직업 성장과 전직

직업마다 별도 레벨과 특성 트리를 가진다. 트리는 초반에 공통 성장 노드를 제공하고, 중반부터 두 갈래 전직으로 분기한다.

| 직업 | 전직 후보 | 대표 스킬 |
|---|---|---|
| 전사 | 버서커, 방패 전사 | 검기 날리기 |
| 궁수 | 신궁, 보우마스터 | 일제사격 |
| 마법사 | 흑마법사, 원소술사 | 파이어볼 → 메테오 |

노드 설계 원칙:

- 초반: 공격력, 체력, 이동 속도, 쿨타임 감소 등 안정적 성장
- 초반 보상감: 공격 범위나 투사체 수 증가를 일부 배치
- 중반: 치명타 확률 증가/치명타 피해 감소처럼 장단점이 공존하는 선택
- 후반: 사거리 감소/근거리 피해 증가처럼 빌드를 크게 바꾸는 선택
- 전직 핵심 노드: 전용 스킬 지급 또는 특정 능력치를 낮추고 다른 능력치를 크게 강화

표시 최대 피해량은 9,999,999를 후보로 둔다.

### 5.3 런 성장

- 전투 및 방 보상으로 아이템 획득
- 아이템 속성 빙고와 시너지 구성
- 같은 스킬이 붙은 아이템을 획득하면 해당 스킬 레벨 상승
- 레벨업, 휴식처, 드롭 포션으로 제한적인 체력 회복
- 일부 장비는 세트가 모이면 인벤토리 한 칸으로 합쳐지는 구조 검토
- 아티팩트 또는 직업 전용 무기 형태의 전용 장비 검토

## 6. 마을

마을은 영구 성장과 다음 런 준비를 담당한다.

- 계정 특성 관리
- 직업 선택, 직업 특성 및 전직 관리
- 업적과 해금 확인
- 장비 및 인벤토리 정비
- 던전 입장
- 성장 기능별 NPC와 간단한 대화
- 필요 시 짧은 스토리와 Cinemachine 연출

던전 입장은 단순 UI 버튼보다 숲이나 관문 같은 장소로 직접 이동해 진입하는 연출을 우선 검토한다.

## 7. 던전과 노드 지도

### 기본 구조

- 시드 기반으로 지도, 방, 보상, 몬스터, 상점 목록, 이벤트를 결정한다.
- 기존 6×8 노드맵은 선택지가 과도할 수 있어 축소한다.
- 시작 노드 선택지는 최대 4개를 기준으로 한다.
- 진행 중 선택지는 최대 6개까지 늘거나 3개로 합쳐질 수 있다.
- 세로 길이는 목표 플레이 시간에 맞춰 조정한다.
- 각 막의 보스 직전에는 휴식 방을 반드시 배치한다.
- 휴식처, 제련소 등 특수 방은 막별 최소/최대 등장 수를 둔다.

### 방 구성

각 테마는 우선 일반 방 3종과 보스 방 1종으로 구성한다. 방 구조를 무작위로 노드에 배치하며, 엘리트 전투도 일반 방 구조를 활용한다.

| 노드 | 기능 |
|---|---|
| 일반 전투 | 전투 종료 후 아이템 보상 |
| 엘리트 전투 | 추가 특성을 가진 강적과 전투, 높은 보상 |
| 보스 | 막 종료 전투 |
| 상점 | 골드로 포션 및 아이템 구매, 아이템 판매 |
| 제련소 | 프레임 강화, 프레임 속성 부여, 아이템 속성 등급 상승 |
| 이벤트 | 다른 방에서 불가능한 특수 선택 제공 |
| 휴식 | 큰 폭의 HP 회복, 제한적 아이템 위치 교환 |
| 미지 | 내용이 숨겨진 랜덤 노드 |

### 방과 구조물

- 평지 기반 3D 전투 공간
- 맵 오브젝트 랜덤 배치
- 탄막 회피와 거리 조절에 활용되는 구조물
- 파괴 가능한 구조물 검토
- 금이 간 벽이나 틈의 빛으로 암시하는 비밀 공간

### 테마

| 막 | 테마 후보 |
|---|---|
| 1막 | 초원, 숲, 해변 |
| 2막 | 정글, 사막, 해저, 탑, 지저 |
| 3막 | 빙하, 용암, 공허, 하늘섬 |

1막 완료 후 해금된 2막 테마를 보여주고 선택하게 한다. 새로 해금된 테마는 다음 런에 최소 한 번 등장하도록 보장하는 방안을 검토한다.

## 8. 전투

### 기본 전투

- 이동과 대시를 통한 회피
- 기본 공격은 자동 조준
- 좌클릭 시 수동 조준
- 직업 액티브 스킬과 아이템 스킬 조합
- 속성에 따라 직업 스킬 효과 변화

예시:

- 전사 검기 + 불: 화상
- 전사 검기 + 물: 동결
- 복수 속성 활성화 시 화상과 동결 동시 적용 가능

### 체력 회복

- 레벨업 시 회복
- 휴식처에서 큰 폭 회복
- 몬스터 처치 시 낮은 확률로 즉시 회복 포션 드롭
- 휴대 포션은 수량을 엄격히 제한

## 9. 몬스터

### 역할 유형

- 근접형
- 원거리형
- 힐러/버퍼형
- 디버퍼형

### 이동 패턴 후보

- 추적, 도망, 비행, 달리기
- 구르기 및 반사 피해
- 숨기, 반투명화, 순간이동

### 공격 패턴 후보

- 돌진
- 직선/포물선 및 단일/다중 투사체
- 잡기 및 플레이어 고정
- 베기, 찌르기, 암살
- 공중 돌진 또는 공중 투사체
- 지속 피해 장판
- 마인 설치
- 상태 이상 부여
- 하수인 소환

### 특수 패턴 후보

- 사망 시 분열 또는 지연 폭발
- 피격 시 은신
- 일정 거리 안의 공격만 받기
- 잠시 나타났다 사라지는 유령
- 골드 또는 아이템을 훔친 뒤 도주
- 황금 고블린
- 시야 감소 또는 강제 줌
- 주변 몬스터 회복
- 파괴 가능한 버프 깃발
- 투사체 반사
- 무작위 스킬 봉인
- 보스의 인벤토리 슬롯 봉인

### 등급

- 일반: 단일 패턴, 별도 특성 없음
- 엘리트: 기본 패턴 2~3개와 난이도에 따른 추가 특성
- 보스: 1~3페이즈와 고유 기믹

엘리트 특성 후보:

- 물리/마법 피해 저항 또는 받는 피해 감소
- 공격력, 공격 속도, 이동 속도 증가
- 회피율, 체력 재생, 보호막 증가
- 점화, 감전, 냉각, 중독, 출혈 부여
- 투사체 추가
- 저주, 기절 등 군중 제어 면역
- 주변 일반 몬스터 사망 시 회복
- 용암, 감전, 냉각, 중독 지대 생성

층과 난이도가 높아질수록 몬스터 수치와 엘리트 특성 수를 늘린다. 난이도는 쉬움, 보통, 어려움, 극악 단계를 후보로 둔다.

### 보스 원칙

- 1~3페이즈
- 광폭화, 피해 구조물, 시야/카메라 활용 기믹 후보
- 마지막 보스는 체력 0 이후의 최종 패턴 후보
- 체력 게이지는 한 줄을 기본으로 검토
- 높은 피해량 빌드는 일부 패턴을 건너뛸 수 있어야 한다.
- 패턴 파훼는 트리거 중심으로 구현한다.
- 목표 콘텐츠: 3개 막에 각 2개 콘셉트, 총 6개 보스 후보

## 10. 아이템과 인벤토리

### 아이템 구성

아이템은 아래 요소의 조합으로 구성한다.

- 등급
- 능력치 증가
- 속성 및 속성 수치(+1, +2, +3 등)
- 액티브 스킬
- 패시브 스킬
- 저주 여부

등급이 높을수록 평균 속성 수치는 높아지지만 항상 상위 등급이 더 높은 수치를 갖지는 않는다. 보상 선택에는 리롤을 제공한다.

### 5×5 인벤토리와 빙고

- 기본 인벤토리 크기: 5×5
- 아이템 획득 시 임의 슬롯 배치
- 재정비 시 아이템 위치 교환
- 빙고 완성 시 속성 시너지 발동
- 아이템마다 속성 수치 보유
- 슬롯 색, 테두리, 이펙트로 특수 슬롯과 속성을 표시
- 금색 슬롯은 해당 속성 빙고를 2배로 계산하는 안 검토
- 일부 아이템 세트는 한 칸으로 합쳐지는 안 검토

속성 활성화 순서와 주/보조 속성 유지 규칙은 별도 명세가 필요하다.

### 속성 체계

| 기본 속성 | 상위/조합 속성 후보 |
|---|---|
| 무 | 조화 |
| 불 | 용암 |
| 물 | 얼음 |
| 풀 | 바람 |
| 땅 | 강철 |
| 어둠 | 공허 |
| 번개 | 빛 |
| 독 | 화학 |
| 저주 | 별도 체계 |

조합 후보:

- 물 + 바람 → 포세이돈
- 어둠 + 독 → 하데스
- 빛 + 조화 → 제우스

상위 속성은 기본 속성 빙고 3줄 완성 시 활성화하는 안을 검토하며, 중복 활성화를 허용한다.

### 아이템 스킬

발동 조건 후보:

- 쿨타임
- 기본 공격 횟수
- 대시 또는 대시 공격
- 제자리 유지 시간
- 엘리트 처치

효과 후보:

- 추가타
- 장판 생성
- 대시 강화
- 직업 스킬 발동 또는 강화 발동
- 영구 능력치 증가

동일 스킬이 여러 아이템에 붙을 수 있으며, 중복 획득 시 스킬 레벨을 올린다. 스킬 계수는 속성 레벨이나 동일 속성 아이템 수를 참조한다.

예시:

```text
화상 1틱 피해 = (기본값 30 × 불 속성 레벨) × 불 속성 아이템 수
```

## 11. 포션

포션 유형:

- 버프형: 현재 전투 또는 일정 시간 동안 능력치 증가
- 투척형: 피해, 디버프, 장판 생성
- 속성 연계형: 포션 획득 확률 및 효과 증가

전투 맵의 구조물 파괴를 주요 획득 경로로 검토한다.

보유 방식 후보는 서로 충돌하므로 플레이 테스트 후 하나를 확정한다.

1. 3슬롯, 슬롯당 1개
2. 2슬롯, 슬롯당 최대 5개
3. 개수 제한 없음

## 12. 특수 방

### 상점

- 포션 구매
- 아이템 구매
- 아이템 판매
- 구매 재화는 골드만 사용할지 결정 필요

### 제련소

- 인벤토리 프레임 강화
- 선택 프레임에 속성 부여
- 아이템 속성 등급 상승

### 이벤트 방

- 아이템 위치 변경권
- 인벤토리 슬롯 강화권
- 아이템 무작위 등급 상승
- 저주 획득 또는 제거
- 골드를 지불하고 이후 전투 버프 획득
- 아이템 변환
- 아이템 대신 저주 획득
- 체력을 지불하고 아이템 또는 골드 획득
- 아이템/체력/골드를 대가로 리롤
- 특수 전투

### 휴식처

- 큰 폭의 HP 회복
- 제한 횟수 아이템 위치 교환(초안: 방문당 3회)

## 13. 업적과 해금

업적 보상 후보:

- 영구 능력치 성장
- 아이템 해금
- 지역/테마 해금
- 추가 직업 해금

업적은 공통 업적과 직업별 업적으로 나누는 안을 검토한다.

- 공통 예시: 몬스터 누적 처치
- 직업 예시: 궁수 스킬 누적 사용

## 14. 세이브/로드

저장 대상:

- 설정
- 계정 특성
- 직업 성장
- 업적 및 해금
- 층/관문 진행
- 중도 종료한 런
- 인벤토리와 아이템 배치

랜덤 결과의 재현성을 위해 런 시드와 시드에서 파생되는 상태를 함께 저장한다.

## 15. 디버그 모드

치트키가 아니라 별도의 UI에서 켜고 끌 수 있게 한다.

필수 기능 후보:

- 모든 장비를 제공하는 테스트 가방
- 인벤토리 무제한 재배치
- 계정, 직업, 런 레벨 조정
- 업적 강제 해금
- 지도 노드 자유 진입
- 몬스터 종류, 등급, 레벨, 수량, 행동 여부 설정
- 엘리트 및 맵 특성 지정
- 보스 패턴/페이즈 강제 발동
- 아이템, 속성, 시너지 데이터 확인
- 세이브/로드 상태 확인

## 16. 챌린지 모드

모든 계정 특성을 해금한 상태에서 플레이하는 별도 모드를 제작한다. 일반 진행과 분리된 규칙, 보상, 기록 방식은 추후 확정한다.

## 17. 기술 및 데이터 원칙

- Unity 6.3 LTS와 Visual Studio 사용
- 시드 기반 절차 생성을 공통 서비스로 관리
- 아이템, 속성, 시너지 등 밸런스 데이터는 CSV 또는 데이터 에셋으로 분리
- 지도는 던전 씬의 Canvas 기반으로 제작
- StageManager가 막, 층, 노드, 방 전환을 관리
- 보스 파훼 판정은 Collider의 Trigger 기반으로 설계
- 개발 초기에는 기본 에셋으로 기능 검증을 우선

## 19. 단기 일정 초안

목표 시점: 7월 중순

| 담당 | 작업 순서 |
|---|---|
| 의현 | 던전 입장 UI → 이동 기능 정리 및 전달 → 시드 → 자동/수동 조준, 고정 카메라 |
| 래호 | 세부 일정 확정 필요 |
| 시우 | 지도 → 역할별 몬스터 → 기본 패턴 → 보스와 패턴 → 엘리트 특성 |

의현의 한 사이클 MVP 작업은 [의현 작업 로드맵](./UiHyeon_MVP_Cycle_Roadmap.md)을 기준으로 진행한다. 선형 던전으로 전체 사이클을 먼저 완성한 뒤 시드 기반 노드 지도로 확장한다.

## 20. 결정이 필요한 항목

### 우선순위 높음

- 한 런의 목표 플레이 시간과 노드맵 세로 길이
- 계정 특성의 최대 레벨과 코스트 규칙
- 직업 레벨 구간과 전직 분기 시점
- 속성 빙고 활성화, 해제, 주/보조 속성 우선순위
- 포션 슬롯 및 중첩 규칙
- 런 중 아이템 재배치 허용 시점과 횟수
- 사망, 중도 포기, 저장/로드 규칙
- 시드가 고정해야 하는 시스템의 정확한 범위

### 프로토타입 검증

- 고정 카메라와 회전 카메라 중 전투 가독성이 좋은 방식
- 5×5 인벤토리가 전투 흐름을 과도하게 끊지 않는지
- 자동 조준과 수동 조준의 조작 충돌 여부
- 패턴 스킵이 보스 난이도를 훼손하지 않으면서 성장 체감을 주는지
- 노드 선택지 4~6개가 실제로 의미 있는 선택을 만드는지

## 21. 권장 구현 순서

1. 게임 시작 → 마을 → 던전 → 전투 → 보상 → 귀환의 최소 사이클
2. 공통 시드 서비스와 노드 지도
3. 플레이어 이동, 대시, 자동/수동 조준
4. 역할별 기본 몬스터와 전투 방
5. 아이템 획득, 5×5 배치, 단일 속성 빙고
6. 상점, 휴식처, 제련소, 이벤트 방
7. 엘리트 특성과 첫 보스
8. 세이브/로드 및 디버그 UI
9. 추가 직업과 전직
10. 2~3막, 업적, 해금, 챌린지 모드
